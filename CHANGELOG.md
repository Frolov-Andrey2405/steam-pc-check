# Changelog

## 0.1 — 2026-11-12

Первая публичная версия.

- Разбор системных требований через Steam API (английский текст) с запасным разбором DOM страницы.
- Сравнение ОС, CPU, ОЗУ, GPU, VRAM, DirectX, диска с индикаторами 🟢🟡🔴⚪.
- База относительной производительности GPU (~230 моделей, включая ноутбучные и встроенные) и эвристическая оценка CPU.
- Прогноз FPS для 7 режимов с диапазоном, 1% Low, стабильностью и уровнем достоверности.
- Использование целей FPS из примечаний разработчика («Low Settings, 60 FPS @ 1080p») как опорных точек.
- Ноутбучные аналоги видеокарт при выборе типа устройства «ноутбук».
- Окно настроек, автоопределение доступных параметров, пользовательские индексы оборудования (JSON).
