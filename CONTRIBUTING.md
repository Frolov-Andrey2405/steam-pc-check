# Как внести вклад

Спасибо за интерес к проекту! Самая полезная помощь — расширение и уточнение базы оборудования и сообщения о неверных результатах.

## Сообщение об ошибке

Приложите, пожалуйста:

- ссылку на страницу игры в Steam;
- браузер и его версию, версию Tampermonkey;
- вашу конфигурацию, как она введена в настройках (CPU, GPU, VRAM, ОЗУ, тип устройства);
- что показал скрипт и что ожидалось (если есть реальные замеры FPS — приложите источник и настройки).

## Добавление оборудования

- **Видеокарты** — массив `GPU_DB` в `steam-pc-check.user.js`. Формат: `['Название', индекс, (1 = встроенная)]`, шкала: GTX 1060 6GB = 100. Для ноутбучных моделей используйте суффикс `Laptop` (например `'GeForce RTX 4060 Laptop'`). Укажите в описании PR источник значения (рейтинг, обзор); значения должны быть воспроизводимы, а не «на глаз».
- **Процессоры** — функция `cpuOne` (формулы по поколениям). Таблицы `INTEL_GEN`, `RYZEN_SERIES` и множители можно уточнять, если есть данные.

Модели, которых нет в базе, пользователь может добавить локально через поле «Свои значения» в настройках.

## Принципы проекта

1. **Достоверность важнее красивых цифр.** Не выдавайте оценку за замер; если данных мало — показывайте это.
2. Не подставляйте «приблизительные» значения вместо того, чего браузер не сообщает.
3. Не ломайте стандартную функциональность Steam; используйте только `GM_*` из `@grant` в шапке.

## Разработка

Нужен Node 18+. Зависимостей нет.

```bash
npm test
```

Команда проверяет синтаксис скрипта и запускает `tests/run-tests.js`. Логика, не завязанная на DOM, экспортируется через `module.exports` в конце файла (в Tampermonkey этот блок не выполняется). Добавляя функциональность, добавьте тест.

## Pull request

- Опишите, что и зачем меняется; для данных — источник.
- Обновите `CHANGELOG.md` и `@version` в шапке скрипта.
- `npm test` должен проходить.
