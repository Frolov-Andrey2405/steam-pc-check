# Steam PC Check

Userscript для Tampermonkey: на странице игры в Steam сравнивает ваш ПК или ноутбук с системными требованиями и показывает **оценочный** прогноз FPS с указанием погрешности.

> **English (short):** a Tampermonkey userscript that compares your PC/laptop against a Steam game's system requirements and shows a rough, clearly-labelled FPS *estimate* (not measured data). Install `steam-pc-check.user.js` in Tampermonkey, open any game page on `store.steampowered.com`, and enter your hardware once. The UI is in Russian.

Проект не связан с Valve и не одобрен ею. Steam — торговая марка Valve Corporation.

## Возможности

- Автоматически читает требования игры (минимальные и рекомендуемые) через Steam API, с запасным разбором самой страницы.
- Сравнивает по каждому параметру: ОС, процессор, ОЗУ, видеокарта, видеопамять, DirectX, диск — индикаторы 🟢 🟡 🔴 ⚪.
- Сравнивает процессоры и видеокарты по относительной производительности, а не по названиям; учитывает ноутбучные версии GPU.
- Прогноз FPS для 7 режимов (от «Минимальные 720p» до «Ультра 4K») с диапазоном, средним, оценкой 1% Low и стабильности.
- Честная маркировка: прогноз всегда подписан как модельная оценка, показывается уровень достоверности, а при нехватке данных прогноз не выводится.
- Характеристики ПК сохраняются средствами Tampermonkey; их можно изменить в любой момент.
- Кэш требований на 24 часа, кнопка «Обновить требования», обработка ошибок, отслеживание переходов между страницами игр.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari).
2. В Chrome/Edge включите «Режим разработчика» на странице расширений (требование новых версий Tampermonkey).
3. Установите скрипт одним из способов:
   - **По ссылке:** откройте `https://raw.githubusercontent.com/<ВАШ_ЛОГИН>/steam-pc-check/main/steam-pc-check.user.js` — Tampermonkey предложит установку.
   - **Вручную:** Tampermonkey → «Создать скрипт» → вставьте содержимое `steam-pc-check.user.js` → `Ctrl+S`.
4. Откройте любую страницу игры, например `https://store.steampowered.com/app/570940/`.

## Первоначальная настройка

При первом открытии страницы игры появится окно настроек:

1. Нажмите **«Определить автоматически»** — подставится то, что браузер реально сообщает: видеокарта (через WebGL), ОС, разрядность, разрешение экрана.
2. Вручную укажите: тип устройства (ПК/ноутбук), **процессор**, **видеопамять**, **ОЗУ**; проверьте видеокарту.
   - Пишите модели как в «Диспетчере задач»: `Intel Core i5-12400F`, `Ryzen 5 5600`, `GeForce RTX 3060`, `RTX 4060 Laptop`.
   - Если в ноутбуке две видеокарты, браузер мог показать встроенную — впишите дискретную.
3. «Сохранить».

Позже изменить данные можно кнопкой **«Изменить характеристики ПК»** в блоке на странице или через меню Tampermonkey.

## Как это работает

### Сравнение комплектующих

- **Видеокарты:** встроенная таблица относительных индексов (GTX 1060 6GB = 100) примерно на 230 моделей, включая ноутбучные и встроенные. Если в требованиях несколько вариантов («GTX 660 / HD 7870»), берётся среднее. Статус: ≥95% от требуемого — 🟢, 75–95% — 🟡, меньше — 🔴.
- **Ноутбуки:** есть отдельные записи для мобильных GPU. Если выбран «ноутбук», а введено настольное название, берётся ноутбучный аналог; если его нет — поправка −30% и статус не выше 🟡.
- **Процессоры:** оценка по формуле «поколение × класс × суффикс» (Intel Core i3–i9 и Ultra, Ryzen, FX, Phenom, Core 2, Pentium, Apple M). Это грубая эвристика, а не таблица замеров.
- **ОЗУ / VRAM:** сравнение объёмов. **ОС:** версия Windows и разрядность. **DirectX:** по версии ОС. **Диск:** проверить из браузера невозможно → ⚪.

### Прогноз FPS

**Это модельная оценка, а не результаты тестов конкретной игры.** Встроенных бенчмарков игр в скрипте нет.

1. Требования разработчика служат опорными точками. Если в примечаниях есть цели вида «Low Settings, 60 FPS @ 1080p», используются они; иначе по умолчанию: рекомендуемое железо ≈ 60 FPS на «Высоких» 1080p, минимальное ≈ 30 FPS на «Низких» 1080p.
2. FPS масштабируется по отношению индекса вашей видеокарты к индексу из требований.
3. Для процессора считается «потолок» FPS; итог — мягкий минимум GPU/CPU.
4. Применяются множители пресета (Минимальные 2.1×, Низкие 1.7×, Средние 1.3×, Высокие 1×, Ультра 0.78×) и разрешения (число пикселей в степени 0.85).
5. Штрафы: ОЗУ ниже минимума ×0.5 (ниже рекомендуемой ×0.92); VRAM ниже оценочной потребности ×0.75 / ×0.5.
6. Диапазон = среднее ± погрешность (±20% при двух опорных точках, ±30% при одной, плюс надбавки за ноутбук и неполные данные). Достоверность: «Средняя» или «Низкая».
7. 1% Low — грубая оценка (≈ 72% от среднего).
8. Если видеокарта не распознана, прогноз не показывается — вместо него объяснение причины.

**Не учитывается:** оптимизация конкретной игры, графический API, DLSS/FSR, драйверы, охлаждение, внутриигровой лимит кадров (например, игры с потолком 60 FPS), поддерживаемые игрой пресеты и разрешения.

### Свои значения для новых моделей

Если вашей видеокарты или процессора нет в базе, добавьте их в окне настроек, поле «Свои значения» (JSON; GTX 1060 6GB = 100, для CPU Core i5-8400 ≈ 105):

```json
{"gpu": {"rtx 5090 laptop": 470}, "cpu": {"ryzen 9 9950x3d": 340}}
```

## Ограничения автоопределения

| Параметр | Что может браузер |
|---|---|
| Видеокарта | Строку WebGL-рендерера (может быть скрыта в Firefox/Safari; при гибридной графике — встроенная) |
| Процессор | Только число логических потоков — **модель вручную** |
| ОЗУ | `deviceMemory` округлён и ограничен 8 ГБ — **вручную** |
| VRAM, тип устройства | Недоступны — **вручную** |
| ОС / разрядность | Через `userAgentData`; Windows 10 и 11 различаются только в Chromium |
| Разрешение | `screen × devicePixelRatio` (приблизительно физическое) |

Скрипт не подставляет «приблизительные» значения: недоступные поля остаются пустыми.

## Точность

- Индексы GPU/CPU приблизительные, собраны по публичным сводным рейтингам и округлены; это не собственные замеры.
- Для игр, где в требованиях нет конкретной видеокарты («DirectX 11-совместимая»), прогноз невозможен.
- Перед покупкой сверяйтесь с независимыми обзорами и бенчмарками именно этой игры.

## Разработка

```bash
npm test        # синтаксис + модульные тесты логики (Node 18+, без зависимостей)
```
